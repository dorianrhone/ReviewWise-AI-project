## Purpose

ReviewWise AI is an AI-powered business intelligence platform designed to help businesses analyze customer reviews, identify recurring feedback, and generate concise, actionable recommendations. Our goal is to help business owners save time, improve customer satisfaction, and make informed decisions.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **AI:** Google Gemini API
- **Database & Authentication:** Supabase (PostgreSQL)
- **Deployment:** Render
- **Version Control:** Git & GitHub
